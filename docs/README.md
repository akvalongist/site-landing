# Minecraft Landing

Одностраничный сайт с изображением Minecraft. Сделано фанатом, неофициальный проект.

## Дополнительно

В репозитории есть страница [shooter.html](shooter.html) с простым шутером от первого лица на Three.js.

Также доступна страница [evolution.html](evolution.html) с симуляцией жизни микроорганизмов. В ней можно управлять своим микробом с помощью клавиш WASD или стрелок.
